# ADR-0006：终端用户身份：消费方签名的用户断言，推荐 RFC 7523 换平台令牌，兼容请求头模式；bind\_policy 默认 strict

- 状态：Proposed
- 日期：2026-10-19
- 关联：docs/architecture.md 第 16.1 节

## 背景

见 docs/architecture.md 对应章节。

## 决策

终端用户身份：消费方签名的用户断言，推荐 RFC 7523 换平台令牌，兼容请求头模式；bind\_policy 默认 strict。详细设计以 docs/architecture.md 为准，本 ADR 只记录决策与取舍。

## 影响

- 修改本决策必须新建 ADR 并将本 ADR 标记为 Superseded。
- 实现与本决策冲突时，先提问，不自行改设计。
