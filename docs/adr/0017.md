# ADR-0017：下游传输与 TLS：策略挂在连接上；默认 custom\_ca 或 pinned；insecure 与 http 为例外（内网、审批、到期日、写类双人复核）；检查在请求前完成；对外统一 HTTPS

- 状态：Accepted
- 日期：2026-10-19
- 关联：docs/architecture.md 第 16.1 节

## 背景

旧系统存在 HTTP、内部 CA 与自签证书；见 9.6 与附录 B。

## 决策

下游传输与 TLS：策略挂在连接上；默认 custom\_ca 或 pinned；insecure 与 http 为例外（内网、审批、到期日、写类双人复核）；检查在请求前完成；对外统一 HTTPS。详细设计以 docs/architecture.md 为准，本 ADR 只记录决策与取舍。

## 影响

- 修改本决策必须新建 ADR 并将本 ADR 标记为 Superseded。
- 实现与本决策冲突时，先提问，不自行改设计。
