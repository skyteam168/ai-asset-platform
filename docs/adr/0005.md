# ADR-0005：认证：控制台本地账号加 TOTP；消费方 client\_credentials（private\_key\_jwt）与静态令牌；OIDC 为可选插件

- 状态：Proposed
- 日期：2026-10-19
- 关联：docs/architecture.md 第 16.1 节

## 背景

见 docs/architecture.md 对应章节。

## 决策

认证：控制台本地账号加 TOTP；消费方 client\_credentials（private\_key\_jwt）与静态令牌；OIDC 为可选插件。详细设计以 docs/architecture.md 为准，本 ADR 只记录决策与取舍。

## 影响

- 修改本决策必须新建 ADR 并将本 ADR 标记为 Superseded。
- 实现与本决策冲突时，先提问，不自行改设计。
