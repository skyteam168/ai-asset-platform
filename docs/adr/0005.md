# ADR-0005：认证：控制台本地账号加 TOTP；消费方 client_credentials（private_key_jwt）与静态令牌；OIDC 为可选插件

- 状态：Accepted
- 日期：2026-10-22
- 关联：docs/architecture.md 第 3、16.1 节；H51

## 背景

控制台默认本地账号 + TOTP；集团可能已有企业 IdP。消费方用 OAuth client_credentials / private_key_jwt 或静态令牌。需固定「外部身份如何进入平台」而不破坏自建 IAM 边界。

## 决策

1. **控制台默认**：argon2id + 强制 TOTP；会话 30 分钟滑动 / 12 小时绝对。
2. **消费方**：`client_credentials`（private_key_jwt）与静态 API Token；用户断言经 `user_binding`。
3. **OIDC / SAML**：可选 AuthProvider 插件；**只**验证身份并返回 `(provider, external_id)`，经 `external_login` 映射到内部 `iam_user`；无映射则 `USER_NOT_BOUND`。**不**读取、不同步、不信任外部返回的组织、角色、密级。
4. **本地验收**：`AIP_OIDC_ENABLED` + stub `id_token`（`stub:<sub>`）；真 IdP（Keycloak 等）在 staging 联调，不阻塞本仓库骨架。

## 影响

- 新增/变更登录插件不得绕过 `external_login`。
- 修改本决策必须新建 ADR 并将本 ADR 标记为 Superseded。
