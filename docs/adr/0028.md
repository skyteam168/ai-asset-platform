# ADR-0028：Credential Manager Cookie / Session（form-urlencoded）

- 状态：Accepted
- 日期：2026-11-10
- 关联：docs/architecture.md §9.2；ADR-0027（login Token 握手）

## 背景

大量老 PHP / ThinkPHP 类后台登录返回 `{"code":1}` 并 `Set-Cookie: PHPSESSID=…`，业务请求靠 Cookie，无 Bearer Token。声明式 `mode=login` 只能从 JSON 抠 Token，接不了这类系统；控制台「登记连接」也不收账号、不测登录。

## 决策

1. 新增 `auth.mode=cookie`：`body_encoding=form|json`，可配 `username_field` / `password_field` / `cookie_name` / `success_when` / `ttl_s`；OpenBao 仍存 `username`/`password`。
2. 登录后缓存 Cookie 值，经 `headers()` 注入 `Cookie: {name}={value}`；single-flight；TTL 优先 `Max-Age`；401 后 `invalidate` 并重登一次（与 declarative 现有重试一致）。
3. `mode=none` 保持一等公民，适配内网部分接口不强制会话。
4. 控制台提供「简易接入」向导：登记连接 → 无认证/Cookie 鉴权（凭据只写 OpenBao）→ 手工登记接口点测 → 勾选生成 Tool 草稿；**不**自动爬全站 API，**不**跳过门禁。

## 影响

- `src/aip/connectors/credentials.py`、`conn` 凭据/测登录 API、`importer/manual`、控制台 `/easy-connect`
- 测例：`tests/test_credential_cookie_session.py`、`tests/test_easy_connect_apis.py`
- 请求级 HMAC 仍走代码 Connector；验证码登录仍要求服务账号（架构 9.2）

## 后果

修改本决策须新建 ADR 并将本 ADR 标为 Superseded。
