# ADR-0003：工作流引擎：自研 step journal 与 DBOS Transact 经 spike 后二选一，保留 WorkflowExecutor 抽象

- 状态：Open
- 日期：2026-10-19
- 关联：docs/architecture.md 第 16.1 节

## 背景

自研 step journal 与 DBOS Transact 在 M5 前做 2 周 spike 后二选一（8.5）。

## 决策

工作流引擎：自研 step journal 与 DBOS Transact 经 spike 后二选一，保留 WorkflowExecutor 抽象。详细设计以 docs/architecture.md 为准，本 ADR 只记录决策与取舍。

## 影响

- 修改本决策必须新建 ADR 并将本 ADR 标记为 Superseded。
- 实现与本决策冲突时，先提问，不自行改设计。
